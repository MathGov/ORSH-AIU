# Historical conditional pairing contract

## 7.3 Conditional pairing, only when its assumptions hold

If all outputs have a common registered meaning, define a declared full-structure distance $d_{\mathcal R}$ and
$$T_{\mathrm{obs}}=\frac1m\sum_{i=1}^m d_{\mathcal R}(D_L(i),D_R(i)).$$
A conditional null must make record-output labels exchangeable across the eligible model units within predeclared strata, given the locality outputs and relevant design covariates. Uniform full permutations within each stratum then form a valid candidate transformation group under that null. Their mean defines a descriptive reference contrast $\Delta_T=\mathbb E_\pi[T_\pi\mid\mathrm{data}]-T_{\mathrm{obs}}$. There is no claim that preserving marginal lists alone proves exchangeability. Fixed points are allowed; a separate estimator excluding them needs a separate justification and is not substituted into the p-value proof.

Common registration is an input to be audited, not an innocent plotting choice. When each model has an arbitrary independent coordinate gauge, cross-model distances can be meaningless until that gauge is fixed from information independent of both outcomes. If suitable nontrivial strata or such registration cannot be justified, report NO_IDENTIFIED_PAIRING_NULL and do not compute a scientific p-value.

No-record frequency is always reported on the full model-history sample. A pairing analysis restricted to record-positive cases is explicitly conditional and cannot replace it. Selection into that subset may itself depend on locality or design covariates, so permutation validity has to be justified again after selection. Direct record-formation rates and conditional frame association are distinct estimands.
